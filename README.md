# Модель классификации возраста пользователей по цифровому следу

## Описание проекта
Разработка ML-модели для предсказания возрастной категории пользователей на основе данных об их поведении в интернете. Проект направлен на обогащение пользовательских профилей для повышения точности и эффективности систем таргетированной рекламы. 

## Бизнес-проблема
Неэффективное расходование маркетингового бюджета из-за показа рекламы нерелевантной аудитории. Отсутствие явных данных о возрасте части пользователей мешает персонализировать рекламные предложения, что приводит к:
- Снижению кликабельности (CTR) и общей конверсии рекламных кампаний.
- Увеличению стоимости привлечения клиента (CAC).
- Показу неподходящего контента уязвимым категориям (например, несовершеннолетним).

## Цель
Создать классификационную ML-модель для распределения пользователей по 5 возрастным когортам (<18, 18-25, 26-40, 41-55, 56+ лет) на основе их цифрового следа (посещения сайтов, типы устройств, использование облака, реакция на рекламу). Требуемое значение метрики качества F1-macro — не менее 0.75.

## Стек технологий
- **Язык и данные:** Python, Pandas, NumPy
- **Машинное обучение:** Scikit-learn (LogisticRegression, OneVsRest, OneVsOne, GridSearchCV)
- **Пайплайны и отбор признаков:** Pipeline, ColumnTransformer, Recursive Feature Elimination (RFE)
- **Анализ и визуализация:** Phik (матрица корреляций), Matplotlib, Seaborn
- **Сериализация:** Joblib

## Структура репозитория
- `notebook.ipynb` — основной файл с исследовательским анализом (EDA), feature engineering, настройкой ML-пайплайнов и подбором гиперпараметров.
- `utils.py` — вспомогательный модуль с функциями обработки данных (агрегация визитов по сессиям/категориям, логарифмирование скошенных распределений, слияние датафреймов).
- `requirements.txt` — список зависимостей для настройки виртуального окружения.
- `models/` — директория для сериализованных артефактов (модель, препроцессор, функции преобразования).

## Результаты работы
1. Проведен EDA 6 разрозненных таблиц (более 5900 уникальных пользователей), выявлен и обработан сильный дисбаланс классов (30.3% пользователей старше 56 лет, всего 8.8% в категории 18-25 лет).
2. Выполнен feature engineering: визиты агрегированы по времени суток и категориям сайтов, применено логарифмирование для нормализации признака total_visits.
3. Построены ML-пайплайны обработки данных (SimpleImputer, StandardScaler, OneHotEncoder) с автоматическим отбором 30 наиболее значимых признаков с помощью алгоритма RFE.
4. Проведен подбор гиперпараметров (GridSearchCV) с кросс-валидацией. Сравнены подходы мультикассовой классификации (OneVsRest, OneVsOne, Multinomial).
5. Обучена финальная модель `LogisticRegression` с балансировкой весов классов (`class_weight='balanced'`).

**Метрики качества на тестовой выборке:**
- **F1 Score macro:** 0.80 (прирост с 0.094 у базовой модели DummyClassifier)
- **Precision macro:** 0.79
- **Recall macro:** 0.81

Пайплайн препроцессинга, логика агрегации и итоговая модель сериализованы (`.joblib`) и готовы к интеграции в production-окружение для классификации новых пользователей.
