# Система прогнозирования продаж для сети дарксторов «Прилавок»

## Описание проекта
Разработка автоматизированной системы прогнозирования недельных продаж с использованием машинного обучения. Проект направлен на оптимизацию процесса управления запасами для сети из 45+ дарксторов. Система предназначена для работы в режиме пакетного вывода (batch inference) с еженедельным циклом переобучения.

## Бизнес-проблема
Текущая система планирования закупок базируется на ручных оценках аналитиков, что влечет за собой следующие проблемы:
- Дефицит товаров в пиковые периоды (недополучение 3–5% выручки).
- Избыточные запасы и списания продуктов с коротким сроком годности (2–3% от выручки).
- Высокие трудозатраты (15–20 часов в неделю на ручное планирование).

## Цель
Создать масштабируемую ML-модель для предсказания еженедельных продаж по каждому отделу даркстора. Готовые прогнозы передаются в ERP-систему для автоматического формирования планов закупок.

## Стек технологий
- Python, PostgreSQL, SQLAlchemy, psycopg2, Pandas, NumPy, Phik, CatBoostRegressor, Scikit-learn, Population Stability Index (PSI), Yandex Cloud S3, Boto3

## Структура репозитория
- `notebook.ipynb` — основной файл с первичным анализом (EDA), очисткой данных, обучением модели CatBoost и оценкой важности признаков.
- `utils.py` — модуль с вынесенными функциями для feature engineering (генерация лагов, скользящих средних, временных признаков) и расчета PSI.
- `requirements.txt` — список зависимостей для воспроизведения среды.
- `.env_temp` — шаблон файла переменных окружения (БД и S3).

## Результаты работы
1. Проведен парсинг и объединение данных из реляционной БД (PostgreSQL).
2. Выполнен feature engineering с использованием исторических данных (лаги продаж на 1, 2, 4 недели, скользящие средние).
3. Настроен мониторинг стабильности признаков (PSI) для фильтрации признаков с сильным дрейфом распределения между обучающей и валидационной выборками.
4. Обучена модель `CatBoostRegressor`. 

Метрики качества на валидационной выборке:
- **MAE:** 1,387.06 руб.
- **RMSE:** 2,950.11 руб.
- **R²:** 0.9817

Итоговая модель сериализуется и автоматически выгружается в S3-бакет для использования в production-окружении.
